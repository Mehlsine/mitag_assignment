## Запуск скрипта
1. Откройте папку со скриптом (там, где лежит файл main.py), зажмите Shift + ПКМ, в контекстоном меню кликните на 'Открыть через PowerShell'
2. В открывшемся окошке введите следующую команду (если не работает с python, то попробуйте python3):
```
python -m venv venv
.\venv\Scripts\Activate.ps1
```
3. В зависимости от вашей ОС и среды терминала команды могут быть другие:
```
macOS / Linux (bash, zsh) -> source venv/bin/activate

Windows (Command Prompt) ->	venv\Scripts\activate.bat

Windows (PowerShell) ->	.\venv\Scripts\Activate.ps1

macOS / Linux (fish) ->	source venv/bin/activate.fish

macOS / Linux (csh/tcsh) ->	source venv/bin/activate.csh
```
4. После успешного захода в venv в терминальной строчке, в самом начале, начнет отображаться (venv)
5. Введите в терминал команду 'pip install pandas'. Дождитесь завершения установки
6. Запустите скрипт командой `python main.py` (или `python3 main.py`)
7. Для детального разбора всех операций зайдите в файл main.py и переведите рубильник (шутка) 'detailed' в значение True
8. После завершения операции в папке появится CSV-файл "daily_by_sku.csv"
